# Security Policy

## Reporting a Vulnerability

Pritrak DLP takes security seriously. If you discover a security vulnerability
in the Pritrak DLP project, please report it responsibly.

**Do NOT open a public GitHub issue for security bugs.**

Instead, email the details directly to: **contact@pritrak.com**

Please include the following in your report:

- A clear description of the vulnerability and its impact.
- The affected component(s) and version(s) (e.g., backend, agent, frontend).
- Steps to reproduce the issue, if possible.
- Any relevant logs, screenshots, or proof-of-concept code.

## What happens next

- We will acknowledge receipt of your report within a reasonable timeframe.
- We will investigate the issue and keep you informed of progress.
- Once a fix is ready, we will release it and coordinate public disclosure
  responsibly, giving you credit unless you prefer to remain anonymous.

## Scope

This policy applies to vulnerabilities in the Pritrak DLP open-source codebase,
including the backend (Go), endpoint agent (C++), and admin console (React).
Third-party dependencies should be reported to their respective maintainers as
well.
